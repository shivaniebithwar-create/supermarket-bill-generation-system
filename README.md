**#** **Supermarket Billing and Inventory Management System**



**##** **Project Description**

A supermarket management application developed using Python and SQLite.



**##** **Technologies Used**

\- Python

\- SQLite

\- Python IDLE



**##** **Features**

\- Add Products

\- View Products

\- Generate Customer Bills

\- Automatic Stock Update

\- View Sales History

&#x20;

**##** **How to Run**

1\. Install Python.

2\. Open the project folder.

3\. Open main.py using Python IDLE.

4\. Press F5 to run the project.
